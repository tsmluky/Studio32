# Studio32

Este repo tiene dos partes con estados muy distintos — no dejes que la primera te
haga pensar que el repo entero está muerto.

## El código de la carpeta `Studio32/` — histórico, no se mantiene

Primera versión de la web de Studio32, de mayo de 2026. Sustituida por
[`studio32-web`](https://github.com/tsmluky/studio32-web). Si buscas la web actual,
el sitio vivo es **[studio32.es](https://studio32.es)** y su código está ahí.

## `notes/` y `reportes/` — vivos, es lo que trae a la gente aquí

- **[`notes/CONTEXTO.md`](notes/CONTEXTO.md)** — arranca aquí si eres un agente nuevo
  en una máquina donde no has trabajado antes. Quién es el equipo, hacia dónde va
  Studio32, y el mapa de todos los repos.
- **[`reportes/ESTADO.md`](reportes/ESTADO.md)** — la foto de negocio siempre actual:
  qué está hecho, qué falta, qué bloquea. En lenguaje llano, para el equipo.
- `reportes/AAAA-MM-DD.md` — un reporte por sesión de trabajo, el histórico.
